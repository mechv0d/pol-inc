# Редактор TARBIN-паков

Графический редактор игровых паков формата TARBIN (tkinter, без внешних зависимостей).
Позволяет открыть JSON пака, отредактировать его и сохранить, а также
посмотреть, какие изображения используются и каких файлов не хватает.

## Запуск

Из корня репозитория:

```bat
.venv\Scripts\python tools\pack_editor\editor.py
```

или как модуль:

```bat
.venv\Scripts\python -m tools.pack_editor.editor
```

## Возможности

- Новый пак с нуля (`Файл → Новый пак`, Ctrl+N): минимальная валидная
  TARBIN-заготовка — заполните вкладки и сохраните.
- Вкладки: Пак (включая settings), Роли, Регионы, Технологии, Действия,
  События (варианты, исходы, эффекты), Al Nazra (намерения и операции),
  Изображения.
- Добавление/удаление ролей, регионов, технологий, действий, событий,
  вариантов, исходов, намерений и операций Al Nazra.
- Эффекты редактируются построчным виджетом (stat/target/delta) везде:
  действия, варианты и исходы событий, операции Al Nazra.
- Проверка пака по тем же pydantic-правилам, что использует движок
  (`Пак → Проверить`, проверка выполняется и перед сохранением).
- Вкладка «Изображения»: собирает баннеры событий и исходов плюс
  `assets.cover` (и глобальные `game_info.jpg` / `game_reg.jpg`), показывает,
  где каждое изображение используется, проверяет наличие файлов
  в выбранной папке, умеет экспортировать список в `.txt`
  и копировать имена в буфер обмена.

## Структура

- `editor.py` — GUI на tkinter.
- `pack_model.py` — логика без GUI (загрузка, валидация, сохранение,
  сбор изображений). Можно использовать отдельно.
