# Редактор GamePack

Графический редактор игровых паков (tkinter, без внешних зависимостей).
Позволяет открыть JSON пака, отредактировать его и сохранить, а также
посмотреть, какие изображения используются и каких файлов не хватает.

## Запуск

Из корня репозитория:

```bat
.venv\Scripts\python tools\pack_editor\editor.py
```

или как модуль:

```bat
.venv\Scripts\python -m tools.pack_editor.editor
```

## Возможности

- Новый пак с нуля (`Файл → Новый пак`, Ctrl+N): заготовка с примером
  фракций и события — заполните вкладки и сохраните.
- Вкладки: Пак, Фракции, Альянсы, Способности, События (с исходами и эффектами).
- Добавление/удаление фракций, альянсов, способностей, событий и исходов.
- Проверка пака по тем же pydantic-правилам, что использует бот
  (`Пак → Проверить`, проверка выполняется и перед сохранением).
- Вкладка «Изображения»: собирает все баннеры событий и исходов
  (плюс глобальные `game_info.jpg` / `game_reg.jpg`), показывает,
  где каждое изображение используется, проверяет наличие файлов
  в выбранной папке, умеет экспортировать список в `.txt`
  и копировать имена в буфер обмена.

## Структура

- `editor.py` — GUI на tkinter.
- `pack_model.py` — логика без GUI (загрузка, валидация, сохранение,
  сбор изображений). Можно использовать отдельно.
